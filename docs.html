快速上手

最简单的方式：打开 whither-production.up.railway.app，直接说话。

试试这些：

国庆从北京去成都玩 3 天，帮我规划行程并导出 PDF

上海 3 日游，带孩子，预算中等

我想去厦门看海，帮我查一下下周的天气和机票

它能做什么

  • 行程规划：根据你的出发地、目的地、天数、预算、偏好，自动生成每天的行程安排
  • 攻略检索：从 4288 条精选攻略里找到最相关的景点和玩法
  • 天气查询：联网实时搜索目的地天气、温度、是否下雨
  • 车次查询：直接对接 12306，查询车次、时刻、余票
  • 交通规划：高德地图给出真实的公交/地铁/打车时长
  • 预算核算：根据行程自动估算交通、餐饮、住宿费用
  • PDF 手册：规划完成后一键生成可下载的 PDF 攻略手册
  • 偏好记忆：填一次出行偏好，后续规划会自动参考

它是怎么做到的

Whither 的大脑是一个 LangGraph Agent——一个能自主决定调用什么工具、按什么顺序调用的状态机。它的工具包括：

工具类型功能
search_travel_knowledge内置4288 条攻略向量检索（DashScope qwen3.7-text-embedding）
search_web_info联网Tavily 实时搜索天气、开放时间等
query_12306_*MCP12306 车次、余票、时刻表
plan_route_between_spotsMCP高德地图真实交通时长
calculate_budget内置自动预算核算
export_itinerary_pdf内置Playwright 生成 PDF 手册

知识库使用 DashScope qwen3.7-text-embedding（默认 1024 维）对攻略做向量化，查询时通过内存矩阵做余弦相似度检索。覆盖国内 107 座城市。

本地运行

想在自己机器上跑 Whither？后端仓库在 GitHub 上开源，直接 Docker 拉起来即可：

# 克隆后端仓库
git clone https://github.com/yijuntuqi/Whither.git
cd Whither

# 配置环境变量（复制 .env.example 为 .env）
# 至少填这几个：
# DASHSCOPE_API_KEY=你的 DashScope Key
# OPENAI_API_KEY=你的 LLM API Key
# TAVILY_API_KEY=你的 Tavily Key

# Docker 一键启动（国内构建加速加 --build-arg USE_TUNA=1）
docker build -t whither:latest .
docker run -p 8000:8000 --env-file .env whither:latest

# 打开 http://localhost:8000 即可使用

或者用 Python 直接跑（需要 Python 3.11+ 和 Node.js 20+）：

pip install -r requirements-runtime.txt
playwright install chromium
python -m uvicorn backend.app.main:app --host 0.0.0.0 --port 8000 --reload

常见问题

覆盖哪些城市？

目前覆盖国内 107 座热门城市，包括所有省会和直辖市。如果你的目的地没有覆盖到，告诉我，我会补充。

PDF 手册怎么下载？

Whither 规划完成后会自动生成 PDF 手册，对话里会出现一个"⬇ 下载 PDF"按钮，点击即可下载。

需要付费吗？

在线体验完全免费。本地运行需要你自己申请 API Key（DashScope 有免费额度）。

支持多轮对话吗？

支持。Whither 会记住当前会话的上下文，可以追问、修改偏好、重新规划。

偏好面板怎么用？

打开体验页面后，往下滚动可以看到"🎯 设置出行偏好"按钮，点击填写你的出行节奏、预算、酒店偏好等。
